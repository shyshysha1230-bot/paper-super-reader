# 元数据规则

元数据只负责**识别与登记**论文的书目信息，**不生成任何总结、分析或评论**。

## 识别对象

按以下字段识别；以论文**首页正式发表信息**为准，PDF 内嵌元数据仅作参考：

- 标题（title）
- 简短标题（short_title）
- 作者列表（authors）
- 第一作者（first_author）、通讯作者（若可见）
- 机构（affiliations）
- 发表年份（year）
- 期刊 / 会议（journal / venue）
- 卷、期、页码 / 文章号
- DOI
- 关键词（keywords）

## 简短标题（Short Title）

- 中文简称，长度约 **3–8 字**。
- 保持原意，**不自行概括或改写论文主题**。
- 仅作目录/文件命名用途，不替代正式标题。

## 缺失与核验

- 任一字段无法确认时，统一写“**待核验**”。
- 不联网查询补全，不凭已有知识猜测，不编造 DOI、年份、作者或页码。
- 若标题含冒号（`:`）等特殊字符，YAML 中整值须用双引号包裹。

## 与报告的关系

- 元数据登记在报告头部的“论文信息”区（模板中的相应字段）。
- 元数据不得混入正文分析；正文只引用已确认的字段值。
