## 目的

先判断论文在做什么，再决定用什么问题阅读。不要仅凭标题或期刊类型分类；优先看研究目的、方法、结果结构和作者对自身工作的定义。分类可以是主类型 + 次类型。

## 类型识别矩阵

| 类型 | 常见特征 | 阅读时的核心对象 |
|---|---|---|
| 原始实证研究 | 作者收集或重新分析数据，报告样本、测量/材料、分析和结果 | 研究问题—设计—数据—分析—结果链 |
| 随机对照/实验研究 | 操纵或分配条件，比较组间结果 | 分配、对照、操纵、依从性、结局 |
| 观察性研究 | 未随机分配暴露；可横断面、病例对照、队列或纵向 | 样本选择、测量、时间顺序、混杂 |
| 质性研究 | 访谈、观察、文本等质性材料；以编码/主题/叙事等分析 | 取样、资料生成、分析路径、反身性 |
| 混合方法研究 | 同一研究有定量和定性组件，并说明整合方式 | 各组件质量及其整合逻辑 |
| 系统综述/范围综述 | 明确检索、筛选、纳入和综合过程 | 检索覆盖、纳排、偏倚、综合方法 |
| Meta-analysis | 对多个研究的效应量进行定量合并 | 效应量、模型、异质性、稳健性 |
| 叙述性综述 | 讨论领域文献，但不一定有可复现检索流程 | 论点结构、文献选择透明度、综合边界 |
| 理论/Perspective/概念论文 | 提出、整合或修订概念、机制或模型；未必有新数据 | 概念定义、论证链、证据来源、可检验预测 |
| 方法/测量/计算论文 | 提出或验证测量工具、算法、统计方法或流程 | 方法定义、验证设计、比较基线、性能指标 |
| 研究方案/Protocol | 预先说明计划做什么，通常没有研究结果 | 研究设计、预注册/计划、可行性；不得报告成已完成研究 |
| 案例报告/病例系列 | 一个或少数案例的详细描述 | 案例选择、资料来源、推论边界 |

## 判定流程

1. 文中是否产生新数据？若是，优先归入实证/方法验证/质性/混合方法。
2. 是否系统检索并按规则筛选文献？若是，归入系统/范围综述；若合并效应量，另标 Meta-analysis。
3. 是否以提出理论框架或观点为核心、没有独立的新样本/实验？归入理论/Perspective/概念论文。
4. 是否主要介绍新工具、量表、算法或分析程序及其验证？归入方法/测量/计算论文。
5. 是否只计划未来研究？归入 Protocol。
6. 若文章多部分混合，注明主次类型，并按章节选择规则。

## 分类边界

- “结果”一词可能指实证结果、综述综合结果、模型推论、方法性能或协议预期；须按类型解释。
- Perspective 可能引用大量实证研究，但这些引用并不自动成为 Perspective 本身的新结果。
- 论文出现“systematic”一词，不足以证明其为系统综述；检查是否报告了可复现检索与筛选过程。
- 论文描述纵向数据不等于因果识别；研究类型标签不能替代对具体设计的说明。
- 类型不明确时，给出最可能分类及不确定性，不要将模糊性隐藏起来。
